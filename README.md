# yfx-eunyoung.github.io

Source for **https://yfx-eunyoung.github.io** (YFXLabs): a static homepage with no build step.

- `index.html`: page markup and content
- `assets/styles.css`: design tokens (dark/light), layout, motion. Desktop ≥ 721px, mobile ≤ 720px
- `assets/main.js`: scroll parallax and frame counter, nav progress, mouse 3D, latest-feed rotation, gallery/card tilt, theme toggle, mobile menu, tabs and carousels
- `favicon.svg`

Preview locally: `python3 -m http.server` → http://localhost:8000
